# 📄 Simple Resume Template

A clean and simple resume/CV template designed using frontend
web technologies.

## 📌 About

This project provides a basic structure for creating a personal
resume or CV in a web-based format.

## ✨ Features

- 👤 Personal information section
- 🎓 Education section
- 💼 Experience section
- 🛠️ Skills section
- 📂 Projects section
- 📞 Contact information
- 🎨 Clean layout

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

This project was created to practice:

- HTML structure
- CSS styling
- Layout design
- Responsive design
- Personal portfolio development

## 🚀 Usage

Download or clone the repository and customize the HTML content
with your own information.
